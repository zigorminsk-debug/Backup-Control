# Backup Control (Android)

Android-приложение на **Kotlin + Jetpack Compose** (`com.zigorminsk.backupcontrol`) для автоматического контроля резервного копирования клиентов по почте **`backup@csl.by`**.

---

## Порядок работы программы

1. **Первичный сбор за 6 месяцев (`backup@csl.by`, IMAP)**
   - Подключение по логину и паролю в режиме `READ_ONLY` (`SSL/TLS 993`, `STARTTLS 143`, автопоиск сервера `mail.csl.by` и поддержка самоподписанных сертификатов).
   - Сканирование писем за последние **6 месяцев** и формирование предварительного списка организаций по отправителю (`From` — адрес и имя).

2. **Редактирование и сохранение списка организаций после сбора за 6 месяцев**
   - Сразу после завершения 6-месячного сбора открывается экран **редактирования и выбора списка организаций** (вкладка **«Организации»**):
     - **Переименование** любой организации (кнопка `✏️`);
     - Редактирование **основного email** и добавление **дополнительных email-адресов** одной и той же организации;
     - **Объединение (`Объединить…`)** двух карточек в одну организацию (если клиент шлёт отчёты с нескольких серверов/ящиков);
     - Индивидуальный порог дней без писем и поле заметки (IP / сервер);
     - Отметка галочками нужных организаций и снятие лишних / старых / служебных адресов;
     - Кнопка **«Сохранить для контроля»**.

3. **Контроль только сохранённых организаций + автодобавление новых при появлении**
   - После сохранения списка ежедневный мониторинг (и утренний баннер) контролирует **только сохранённые организации**.
   - Снятые/удалённые при редактировании адреса сохраняются в разделе **«Исключённые»**, поэтому они не тревожат уведомлениями и не подтягиваются заново из старых писем (при необходимости любую организацию можно вернуть в контроль в один тап).
   - Если после сохранения списка на `backup@csl.by` приходит письмо от **нового, ранее неизвестного отправителя**, программа **автоматически добавляет новую организацию в список контроля** и помечает её значком **`НОВАЯ`**, чтобы её сразу было видно и можно было при желании переименовать или исключить.

4. **Ежедневная проверка в 09:20 (Пн–Пт) и утренний баннер**
   - Автоматический фоновый сбор в **09:20 с понедельника по пятницу** (`AlarmManager` + `WorkManager`).
   - Универсальное распознавание отчётов на русском и английском языках (**Veeam, Acronis, Cobian, Proxmox, Synology, 1С, SQL, скрипты**), включая контроль нескольких независимых заданий у одного клиента за ночь.
   - Всплывающий системный баннер Android и красный баннер в приложении со списком сохранённых организаций, у которых **ошибка бэкапа** или **несколько дней не было почты**.

5. **Автообновление через GitHub Releases**
   - Приложение подписано постоянным ключом `release-key/backup-control-release.p12` (`SIGNING.md`) и умеет проверять и устанавливать новые выпуски `Backup-Control.apk` прямо из вкладки **«Настройки»**.

---

## Скачивание и установка APK

- **Последний подписанный релиз:** откройте раздел **Releases** репозитория (`Backup-Control.apk`) или обновите приложение прямо через кнопку **«Проверить обновления на GitHub»** внутри программы.
- **Локальная сборка:**
  ```bash
  ./gradlew testReleaseUnitTest assembleRelease
  ```
