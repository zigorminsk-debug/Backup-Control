# Backup Control (Android)

Android-приложение на **Kotlin + Jetpack Compose** для автоматического контроля резервного копирования по почте **`backup@csl.by`**.

---

## Основные возможности

1. **Прямое подключение к `backup@csl.by` по логину и паролю (IMAP)**
   - Поддержка `SSL/TLS (993)`, `STARTTLS (143)` и `Plain (143)`.
   - Поддержка корпоративных и самоподписанных SSL-сертификатов.
   - Автоматический поиск IMAP-сервера (`mail.csl.by`, `imap.csl.by`, `mail.hoster.by`, `imap.yandex.by` и др.), если адрес сервера заранее неизвестен.
   - Чтение писем в режиме **`READ_ONLY`** — приложение не удаляет письма и не снимает отметку «Непрочитано» в почтовом ящике.

2. **Первичный сбор за 6 месяцев**
   - При первом запуске приложение сканирует почту за последние **6 месяцев** (глубина настраивается).
   - Автоматически формирует **список организаций по отправителю (`From` — email и имя отправителя)**:
     - Корректно разделяет разных клиентов даже в случае отправки через общий ящик `backup@csl.by` с разными именами в поле `From`.
     - Поддерживает кириллические кодировки `UTF-8`, `Windows-1251`, `KOI8-R`, а также HTML-отчёты.
     - Любую организацию можно переименовать, задать индивидуальный порог дней молчания или отключить из мониторинга (например, служебные рассылки).

3. **Универсальный анализ ошибок бэкапов (RU / EN)**
   - Распознаёт отчёты от **Veeam**, **Acronis**, **Cobian Backup / Reflector**, **Uranium**, **Proxmox (`vzdump` / PBS)**, **Synology Hyper Backup**, скриптов **1С**, **SQL Server**, **PostgreSQL**, **7-Zip / PowerShell / Bash**.
   - Учитывает нулевые счётчики (`Ошибок: 0`, `Errors: 0`, `без ошибок`, `exit code: 0`), не создавая ложных тревог.
   - Отслеживает несколько разных заданий (jobs) у одной организации в течение суток: если ночью задание 1С завершилось с ошибкой, а файловый бэкап прошёл успешно — ошибка не затрётся и попадёт в утреннюю сводку.

4. **Ежедневная проверка в 09:20 с понедельника по пятницу**
   - Автоматический запуск в фоне (`AlarmManager` + `WorkManager` + автовосстановление расписания после перезагрузки телефона).
   - Настраиваемый порог отсутствия писем (по умолчанию **3 дня**, с опцией учёта только рабочих дней Пн–Пт).

5. **Утренний баннер с уведомлением**
   - Если у одной или нескольких организаций обнаружена **ошибка бэкапа** либо **несколько дней не было почты**, в **09:20** появляется:
     - **Всплывающий системный баннер Android (Heads-Up Notification)** поверх экрана со списком проблемных организаций;
     - **Заметный красный баннер тревоги** в верхней части главного экрана приложения с разделением на категории *«Ошибка резервного копирования»* и *«Нет почты от клиента несколько дней»*.
   - Если у всех организаций всё в порядке — ложных тревожных баннеров нет.

## Установка готового APK

### Вариант 1: Скачать собранный APK из GitHub Actions
1. Откройте вкладку **Actions** в репозитории GitHub -> workflow **Build Android APK**.
2. Откройте последний успешный запуск и скачайте артефакт **`BackupControl-APK`** (внутри находится файл `BackupControl.apk`).
3. Передайте `BackupControl.apk` на Android-смартфон (Android 8.0 / API 26 и выше) и установите его.

### Вариант 2: Локальная сборка в Android Studio или через консоль
Требуется **JDK 17** и **Android SDK (API 35)**:

```bash
./gradlew testDebugUnitTest assembleDebug
```

Готовый установочный файл появится по пути:
`app/build/outputs/apk/debug/app-debug.apk`

## Быстрый старт после установки на телефон

1. Откройте **Backup Control** и разрешите показ уведомлений.
2. На стартовом экране уже подставлен логин `backup@csl.by` (и сервер `mail.csl.by:993`). Введите пароль и нажмите **«Собрать за 6 мес.»** (при желании сначала нажмите *«Проверить вход»*).
3. Дождитесь окончания первичного сбора списка организаций.
4. Перейдите на вкладку **«Настройки» -> «4. Разрешения Android для работы в 09:20»** и при необходимости включите:
   - **Точный будильник в 09:20**
   - **Работа в фоне без экономии заряда** (особенно важно на оболочках Xiaomi HyperOS/MIUI, Samsung OneUI, Huawei/Honor).
5. Нажмите **«Тест утреннего баннера уведомлений»** в настройках, чтобы убедиться, что всплывающий баннер отображается на экране телефона.

## Структура проекта

- `app/src/main/java/by/csl/backupcontrol/domain/` — модели, анализатор статусов бэкапов (`BackupStatusAnalyzer`), извлечение организаций по `From` (`OrganizationExtractor`), декодер `RFC 2047 / Windows-1251 / HTML`, расчёт расписания Пн–Пт 09:20.
- `app/src/main/java/by/csl/backupcontrol/data/` — IMAP-клиент (`ImapMailClient`, `MimeMessageExtractor`), база данных Room (`BackupDatabase`), зашифрованное хранилище настроек и пароля (`SecureSettingsStore`), репозиторий синхронизации.
- `app/src/main/java/by/csl/backupcontrol/worker/` — планировщик `09:20 Пн–Пт` (`BackupScheduleManager`, `AlarmReceiver`, `BootAndTimeChangeReceiver`), фоновый воркер (`BackupCheckWorker`) и генератор баннера уведомлений (`MorningBannerNotifier`).
- `app/src/main/java/by/csl/backupcontrol/ui/` — интерфейс на Jetpack Compose (Material 3): главный экран со сводкой и баннером тревоги, карточка организации, журнал проверок и экран настроек.
- `app/src/test/java/by/csl/backupcontrol/` — модульные тесты анализатора писем, группировки организаций, расписания и логики тревог.
